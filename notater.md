## Nyttige kommandoer

| Kommando | Hva den gjør |
|---|---|
| `pwd` | Viser hvilken mappe jeg står i |
| `ls` | Viser filer og mapper |
| `cd mappe` | Går inn i en mappe |
| `cd ..` | Går ett nivå opp |
| `git status` | Viser hva som er endret |
| `git diff` | Viser nøyaktig hvilke linjer som er endret |
| `git add .` | Merker alle endringer for lagring |
| `git commit -m "tekst"` | Lagrer et øyeblikksbilde |
| `git log --oneline` | Viser historikken |
