# Instruksjoner for Claude

Dette repoet brukes til å lære Claude Code gjennom kurset Claude Code 101.

## Om meg
- Jeg er nybegynner og har ikke programmert før.
- Jeg bruker Claude Code i nettleseren (claude.ai/code), fordi jobbmaskinen min ikke har terminaltilgang.

## Slik vil jeg at du jobber
- Svar alltid på norsk.
- Forklar enkelt og unngå faguttrykk, eller forklar dem kort når du bruker dem.
- Vis meg hva du har endret (diff) og forklar det før du lagrer noe.
- Lag en egen gren (branch) for hver endring, slik at jeg kan se over den i en pull request.
- Skriv commit-meldinger på norsk.

## Om repoet
- `notater.md` – min huskeliste og mine notater fra kurset.
